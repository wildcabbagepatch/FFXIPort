## RC5 (live 0x017 reception) — changes relative to RC4

| File | Change |
|------|--------|
| `client/FFXIPort/ffxiport/fpx.lua` | `readChat` reads the LSB packet layout in pure Lua (no `struct`): Kind at 0x04, sName at 0x08, Mes up to 150 bytes at 0x17, which may have no terminating NUL. `rejectReason`: trusted only if Kind 29 and the speaker is empty or exactly `P.localName()`; unknown local name → not trusted. Reasons `mode` / `sender` / `sender-unknown` are counted as foreign; adds `lastForeign()`. `MAX_FRAME_LINE` 150, `MAX_CHUNK` 128. |

| `tests/lib/packets.lua` | Added: realistic 0x017 packets built like LSB's `GP_SERV_COMMAND_CHAT_STD` (header, Kind, Attr, zone, 15-byte name, 150-byte message cap, 4-byte padding). |

## RC4 (request-id reuse on rapid reload) — changes relative to RC3

| File | Change |
|------|--------|
| `client/FFXIPort/ffxiport/fpx.lua` | New client session id per load and per `reset()` (12 hex: low 32 bits of the ms clock + 4 random digits; RNG seeded from time, CPU clock and ms clock). Request lines carry it: `!fpx 1 <sid> <rid> …`. The RID counter is seeded from the session id instead of `os.time()`. Adds `sessionId()` and a `_setRidCounter` test hook. |
| `client/FFXIPort/ffxiport/echo.lua` | Echo patterns include the session id. |
| `client/FFXIPort/FFXIPort.lua` | Header comment; version `1.1.0-rc.4`. |
| `server/modules/custom/late/fpxport.lua` | `parseRequest` requires `<sid>` (12 lowercase hex), otherwise `BADREQ`. The replay cache is keyed by `M.replayKey(sid, rid)`. Rate limit and cooldown unchanged (per character). Incidents record the `sid`. |
| `tests/server/test_fpxport.lua` | Requests carry a session id (helper). New: missing or malformed sid; SYNC and GO request-id collisions across sessions with changed balances; same-session replay; shared rate limit. 66 tests. |
| `tests/client/test_client.lua` | Request shapes with sid. New: fresh loads in the same second get different session ids; a session reset changes the id; SYNC and GO collisions after a simulated reload (forced equal RID, changed balances, end-to-end against the server); same-session retransmission still replayed. 54 tests. |
| `docs/PROTOCOL-FPX1.md` | §2 SID, §3 grammar, §3.3 session identifier, §8.2 replay keyed by SID + RID, §9 examples (also updated to RC3 prices). |
| `docs/SERVER-MODULE.md`, `docs/ACCEPTANCE-M8.md`, `docs/TEST-RESULTS-M8.md`, `docs/CLEANROOM.md`, `README.md` | RC4 notes, reload acceptance item, results. |

## RC3 (final transaction fixes, final pricing) — changes relative to RC2

| File | Change |
|------|--------|
| `server/modules/custom/late/fpxport.lua` | Fixed prices in `M.config.prices` (H/S/G 1000 gil or 100 CP, R 1000 gil or 100 IS). Removed fee multipliers, Rhapsody discount and Captain exemption. New `M.cityGroupOfZone` / `M.cityOf` / `M.sameCity` (same-city trips free, generated from LSB data). Transaction: refunds confirmed by re-reading the balance (`refundConfirmed`). New final outcome `E UNSURE` with a full-context `CURRENCY INCIDENT`. A move failure after `T` sends a same-RID correction that replaces `T` in the replay cache. Notices claim a refund only when confirmed. |
| `client/FFXIPort/ffxiport/fpx.lua` | Correction window after `T` (`CORRECTION_MS` 6 s, `closeCorrection`, `correctionOpen`); a correcting `E` or an unreadable response in the window is delivered as `onTravel{correction=true}`. |
| `client/FFXIPort/ffxiport/travel.lua` | Handles corrections (`INTERNAL` → failed, refund confirmed; `UNSURE`, unreadable correction or a missing expected zone change → uncertain + reconcile record). `E UNSURE` without `T` → uncertain. "Travel complete" only after a zone change, or after the correction window for same-zone destinations. Closes the correction window when zoning starts. `INTERNAL`/`UNSURE` texts. |
| `client/FFXIPort/FFXIPort.lua` | `/port status` shows a pending reconciliation; version `1.1.0-rc.3`. |
| `tests/server/test_fpxport.lua` | Rewritten for the final prices and outcomes: 60 tests (pricing per category and currency, same-city rules incl. Chateau / Heavens Tower / Al Zahbi, transaction outcomes incl. corrections, refund failure/verification, incident context, replay, 28-case fault matrix). |
| `tests/client/test_client.lua` | 49 tests: prices updated; new corrections / reconciliation / same-zone completion / duplicate T / closed window tests; client-server price consistency over all catalogue rows; Chateau free travel. |
| `tests/lib/lsb_mock.lua` | Survival Guide 0 (Northern San d'Oria) added to the mock map. |
| `tools/gen_city_groups.lua` | Added: derives the city table from LSB `homepoint.lua`, `zoneutils.cpp` and `data/zones/*/zone.yaml`; check mode compares it with the module. |
| `docs/PROTOCOL-FPX1.md` | §4.6 final outcome and correction rule; §6 `UNSURE`, `INTERNAL` clarified; §8.1 correction window. Frame/body grammar unchanged. |
| `docs/SERVER-MODULE.md`, `docs/ACCEPTANCE-M8.md`, `docs/TEST-RESULTS-M8.md`, `docs/CLEANROOM.md`, `docs/PROVENANCE-M8.md`, `README.md` | Final prices, same-city rule, outcomes, incidents, results, release notes; provisional-pricing language removed. |
