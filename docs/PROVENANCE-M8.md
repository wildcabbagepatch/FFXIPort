## Clean-room scope (precise)

* **Clean:** the FPX/1 design; `fpx.lua`; `fpxport.lua`; all tests.
  Their authors had no access to Driftwood/dwport, the previous server module,
  the previous protocol module or old protocol documents/fixtures.
* **Not clean-room, by design:** the adapted client integration modules. They
  are the owner's existing independent code, edited with knowledge of their
  previous contents (which named the old commands). The old content was
  removed, not carried into FPX/1.
* **Inherited data:** `catalog_data.lua` was generated earlier from Phoenix/LSB
  sources plus the previous server module (see its header). It is used as the
  permitted "existing game catalog". Every value used was re-verified against
  upstream LSB (193/193 rows).
* **Limits:** see `docs/CLEANROOM.md` § Boundary notes (model knowledge;
  Phoenix not available, upstream LSB used).

Access chronology: `docs/CLEANROOM.md`.

## 1.1.0 — public release

* **Catalogue.** `client/FFXIPort/ffxiport/catalog_data.lua` (version 7) is
  regenerated by `tools/gen_catalog.lua` (new, GPL-3.0-only, © 2026 wildthing)
  from LandSandBoat sources plus `tools/catalog_facts.lua` (new, hand-maintained
  scope, zone expansion labels, Gate Crystal order and Runic Portal labels,
  written for 1.1.0). No earlier FFXIPort server module, protocol, catalogue
  or generator input is an input. The previous catalogue (version 6, whose
  generator header listed the earlier server module among its inputs) was
  used only afterwards, to verify that all 193 rows are unchanged. That
  history is recorded here and in docs/CATALOGUE.md, not erased.
* **Unchanged inherited data.** `homepoint_suffix_data.lua` (Home Point E/A/M
  location suffixes, attributed to BG-Wiki in its header; all 35 designations
  checked by hand by the project owner against what FINAL FANTASY XI displays
  before the 1.1.0 release) is unchanged and is
  listed as an open question in NOTICE.md.
* **Unchanged inherited client code.** `catalog.lua` (one version check and a
  comment changed in 1.1.0), `config.lua`, `zone.lua`, `chatlog.lua`,
  `ui/rows.lua`, `ui/theme.lua` and most of `ui/window.lua` are the project's
  existing independent client code.
* **New in 1.1.0:** `tests/client/test_addon_smoke.lua`, `tests/lib/packets.lua`,
  `tools/gen_catalog.lua`, `tools/catalog_facts.lua`, README.md, INSTALL.md,
  CHANGELOG.md, NOTICE.md, docs/CATALOGUE.md, docs/RELEASE-READINESS.md.
